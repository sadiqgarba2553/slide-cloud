# Slide Cloud design system

Slide Cloud is the orange presentation member of the BlueCloud desktop family. Its interface shares Doc Cloud and Sheet Cloud's local library, quiet sidebar, practical toolbar, local save status and native backup workflow.

- Brand asset: supplied orange presentation artwork, clipped with the same superellipse squircle as its siblings. Keep it unaltered; do not substitute Microsoft's identity.
- Typography: platform system stack (Segoe UI on Windows), 13px base, 11–12px controls, 9–10px supporting labels, 35px library heading, restrained medium/semibold weights. Slide content fonts are independently editable.
- Colors: paper #FAF9F7, white surfaces, ink #292725, muted #78716B, warm borders #E6E2DC, action orange #B84D1C, pale selection #FBECE2. Dark mode uses solid charcoal and a readable warm accent.
- Layout: library sidebar and editorial template strip; editor header, small ribbon, ordered slide filmstrip, 16:9 fitted canvas, optional private notes, precise object inspector. No unnecessary decorative cards or floating controls.
- Spacing: 4/8/12/16/24/32/48px rhythm. 6–9px control radii, 1px borders, subtle canvas elevation. Fullwidth content workspaces stay calm.
- Interactions: explicit selected-object outline, visible focus, disabled unavailable commands, accessible labels and native modal dialogs. Escape dismisses dialogs/slideshow; standard save, undo and duplicate shortcuts are supported. No gradients, glass, neon or entrance effects. Hover colors only; reduced-motion removes transitions.
- Responsive behavior: fit the canvas to its available width and height, compress the filmstrip/toolbar on smaller windows, keep geometry controls at desktop widths, and collapse library navigation for narrow browser views. Native editing targets windows of 1000px or wider.
- Honest status: saved means the local library; native export is a separate disk copy. Alpha conversion boundaries are exposed in File and release notes. Speaker notes are excluded from audience slideshow and print.
