# Slide Cloud alpha boundaries

Slide Cloud is an independent, local-first presentation editor. Its native format preserves its supported editable slide content. It is not full Microsoft PowerPoint compatibility.

- **Native format:** `.slidecloud` is versioned JSON with embedded raster images, slide order, element geometry, notes and named version snapshots. Limit: 200 slides, 300 elements per slide, 10,000 elements per snapshot, 30 named versions and approximately 32 MB serialized text. Native files are not encrypted. Clearing application data can remove the local library; export backups.
- **Objects:** editable text boxes, rectangles, ellipses, lines and embedded PNG/JPEG/GIF/WebP images. There are no editable charts, tables, SmartArt, freeform paths, media playback, embedded OLE documents, equations, hyperlinks, group editing or full PowerPoint master/layout systems. GIF/WebP become static PNG images when exporting to PPTX.
- **PPTX export:** generates actual OOXML presentations with editable text boxes, the supported shapes, embedded raster images and speaker notes. Uses a fixed 16:9 canvas. Fonts, line wrapping and text measurement depend on the viewer; no pixel-identical PowerPoint layout is promised. Unsupported native objects are not silently represented as full PowerPoint features.
- **PPTX import:** reads the presentation's relationship-defined slide order, explicit positions/sizes, basic text, first-run text style, basic solid colors, basic rectangles/ellipses/lines, supported embedded images and body speaker notes. Rich mixed runs flatten to one style. Unsupported geometry may become rectangles. Cropping, theme inheritance, inherited master/layout content and exact typography are not preserved; layout-dependent placeholder positions are approximated. Non-16:9 documents scale to 16:9. Groups, tables, charts, SmartArt, transitions, animations, video/audio, OLE objects, external images, comments and full PowerPoint fidelity remain unsupported. A visible import warning describes these limits.
- **Import safety boundaries:** PPTX input is capped at 32 MB compressed, 80 MB advertised total expansion, 3,000 members, 16 MB advertised per member, 2 MB actual per XML part and 8 MB actual per supported image. Actual streaming reads also stop at an 80 MB cumulative expanded-byte budget, even if ZIP metadata lies. Encrypted, multipart, ZIP64, unsafe/duplicate paths and XML entity declarations are rejected. No externally linked content is fetched. These bounds are tested; they do not constitute a complete hostile-file security audit.
- **Presentation and printing:** slideshow, notes and print/PDF behavior use the browser/WebView runtime. Physical printers, multi-monitor presenter mode, remote controls and assistive technologies require further validation. There is no hosted collaboration, cloud sync, account service, VBA or legacy `.ppt` support.
- **Desktop scope:** this release targets Windows x64. Windows publisher signing, clean-machine installation/uninstallation, full native dialog round trips, macOS/Linux/ARM64 and large-deck performance require separate validation. The packaged test report records what was actually exercised.

Retain an original `.pptx` separately before converting. Native originals and exports are independent documents; compatibility conversion is not an archival substitute for the original file.
