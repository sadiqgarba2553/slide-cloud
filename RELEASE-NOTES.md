# Slide Cloud 0.1.0 for Windows

The first free Windows alpha of Slide Cloud joins Doc Cloud and Sheet Cloud in BlueCloud Launcher.

- **New presentation logo.** The supplied orange presentation artwork appears within the same squircle icon system in the app and Windows packaging.
- **Local slide workspace.** Editable slides with text, shapes and images, slide organization, speaker notes and a slideshow view.
- **Editable templates.** Start from a structured presentation and customize the actual slide content.
- **Native presentation backups.** Save `.slidecloud` files to retain Slide Cloud's supported editable content.
- **Basic PPTX exchange.** Import and export a bounded subset of PowerPoint presentation content. Keep source files and native backups; this release does not provide complete PowerPoint fidelity.
- **Updated launcher and release systems.** Install and manage Slide Cloud using the existing signed release feed, SHA-256 package checks, resumable downloads and app-owned release repository.

Install through BlueCloud Launcher 0.7.2 or download **Slide-Cloud-0.1.0-x64-setup.exe**. Microsoft WebView2 is required for the managed Windows executable. Source code, managed ZIP, standalone installer, app metadata and checksums accompany the release.

Unsigned Windows x64 alpha development release. Animations, transitions, embedded media, full Office compatibility and hosted collaboration are outside this release. Clean-machine installer/uninstaller, full native dialog save/reopen and macOS/Linux/ARM64 distribution are not claimed verified. See `docs/KNOWN_LIMITATIONS.md` and the current validation report for the tested scope.
