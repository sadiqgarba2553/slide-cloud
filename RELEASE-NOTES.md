# Slide Cloud 0.2.0

Editable tables and chart data, more vector shapes, slideshow transitions and entrance effects with reduced-motion support, and a same-window presenter console. Improved table PPTX exchange and chart-family export. Existing decks and orange squircle branding are preserved. Multi-monitor presenting and full PowerPoint fidelity are not included.

Windows x64 alpha. Public Windows publisher signing is not available. See docs/CODEX_VERIFICATION.md for tested behavior and known limitations. Back up important work using the native file format before updating.
